# QSpot — monochrome travel console

The product is a real UNO Q travel router, used at a desk or from a phone. The job is to connect, understand the actual network state, and make changes with confidence.

Palette: carbon #080808, graphite #111111, divider #262626, silver #999999, porcelain #f5f5f5, white #ffffff. Light mode reverses the surface roles. No chromatic accents.

Type: locally bundled Geist Variable. Display 56–72px / weight 500 / tight tracking; page titles 30–36px; controls and content 14–15px. Numeric information uses tabular figures.

Login: a generous left-aligned identity statement and an abstract LED-inspired connection sculpture; a compact sign-in form to the right. Mobile keeps the form primary. Avoid a generic gradient and avoid a fake performance claim.

```
LOGIN                      ADMIN
QSpot              local   sidebar | live connection route
                                   | measured traffic
connection sculpture form          | guests + router health
short promise        sign in       | settings via focused sheets
```

Onboarding is an actual sequence: existing internet source → own network → guest limits → finish. Each step changes one thing. Existing values are loaded from the router. Finishing applies validated configuration and presents the reachability confirmation.

The LED matrix is the signature detail. A brief, single connection reveal and user-driven step transitions communicate responsiveness. No continuous ornamental motion. Reduced motion removes travel and scale transitions.

All status and traffic values come from the authenticated API. A disconnected state is explicit. The interface does not imply VPN protection while the tunnel is off or blocked.
